# 中文知识库系统 MVP 验收清单

> **版本**：v1.0
> **日期**：2026-04-30
> **说明**：本文档用于约束 MVP 开发阶段的最小交付范围，避免开发范围漂移。

---

## 一、验收目标

MVP 阶段必须完成以下 4 项核心能力：

- Markdown 文档可稳定入库
- 全文检索与向量检索可用
- 输入文本可输出结构化 claim 质检结果
- 人工审核结果可持久化查询

不属于本次验收范围：

- 知识图谱
- 批量质检
- 默认整篇长上下文注入
- 多模型投票常态化
- 对外开放 API 平台化能力
- 高风险专业推荐能力
