# Legacy 兼容分支退出计划

> 日期：2026-07-17
>
> 原则：兼容逻辑只为已存在的数据和索引服务，不作为新功能入口；不晚于 1.0.0 发布评审时逐项删除或书面延期。

## 1. 范围与截止点

| 兼容分支 | 当前用途 | 可删除条件 | 截止版本 |
|---|---|---|---|
| `src/auth/service.py` 旧页签名与 SHA256 密码 | 允许历史账号登录后升级密码、读取旧权限名 | 活动用户密码均为 `pbkdf2_sha256$`；权限表不再出现旧页签名；连续两个发布周期无旧格式命中 | 1.0.0 发布评审前 |
| `src/db/connection.py` 旧权限表与缺列预升级 | 让早期 SQLite 库可启动并升级到当前结构 | 所有受支持备份均完成当前 schema 初始化；发布说明明确最低数据库基线；恢复演练不再需要预升级分支 | 1.0.0 发布评审前 |
| `src/knowledge_base/service.py` 默认库根目录文档迁移 | 将早期根目录文档归入 `Input/default` 并修复数据库路径 | 活动库不存在默认库根目录文件；`documents.source_path` 均为知识库相对路径；连续两个发布周期迁移结果为空 | 1.0.0 发布评审前 |
| `src/retrieval/vector_store.py` 旧 Chroma 配置自修复 | 备份不兼容集合并从 SQLite 回填当前向量索引 | 所有活动索引均为当前指纹与维度；连续两个发布周期无 `legacy_collection_config` 修复事件；恢复演练通过 | 1.0.0 发布评审前 |
| `src/pageindex/service.py` 旧树结构兼容 | 读取尚未通过当前结构质量门禁的历史 PageIndex | 所有活动 PageIndex 已按当前版本重建；状态不再出现 `legacy`；历史问答回放通过 | 1.0.0 发布评审前 |
| `Docs/migrations/_apply_auth*.py` 归档脚本 | 保留早期认证改造过程供审计，不属于正式迁移入口 | 当前认证迁移和恢复文档已覆盖必要历史；代码审计确认无运行入口引用 | 1.0.0 发布评审前 |

## 2. 删除前验证

1. 只读检查活动 SQLite 的用户密码前缀、权限名称、schema 和文档路径。
2. 检查检索索引状态与 PageIndex 记录，确认没有旧格式或 `legacy` 状态。
3. 对最新备份执行恢复 dry-run，并运行完整 Ruff、Mypy、Pytest、build 和 compileall。
4. 每个删除项独立提交，保留对应备份位置、回滚命令和验证输出。

## 3. 约束

- 未满足删除条件时不得直接移除兼容分支；若 1.0.0 评审仍需保留，必须在本文件记录命中数据、责任人、延期版本和重新评审日期。
- 新写入的数据、密码、索引和 PageIndex 不得继续产生旧格式。
- `Docs/migrations` 脚本只接受静态检查，禁止执行；正式迁移必须进入受测试的项目代码并提供恢复方案。
